# 產科學習室介面規格

本次由使用者授權開始第一階段，獨立於既有產房模擬。第一個交付為胎位辨識完整試教流程。

視覺參考為同資料夾的 interface-concept.png，由內建 Image Gen 產生的介面概念，僅作設計參考；不當作模型或醫學證據。

- 主背景純白，文字深藍 #142f46，次要文字 #647887，重點青綠 #138a96，細分隔線 #dce5e9。
- 模型觀察區淡藍灰 #e9f0f4，骨盆骨白，胎兒暖陶色；使用即時 3D，不能以截圖替代互動。
- 頁首品牌、四模組簡潔導覽；三個尚未製作模組清楚標示製作階段。
- 桌面主畫面為大觀察區加右側教學欄；下方六種胎位按鈕。手機改為觀察區在上、教學欄在下，保留核心功能。
- 標題 36–40px、正文 17–18px、控制 15–16px；觸控至少 44px。
- 模式：示範教學、自由探索、自我測驗。攝影機觀察與胎兒姿態分開；測驗不能修改胎位。
- 核心元件：文字頁籤、扁平側欄、明確按鈕、細分隔線；避免層疊卡片。
- 圖示使用 Lucide 的視角、旋轉、縮放、方向箭頭、清除及確認語意。文字、控制與學習資料由程式實作。

醫學模型與概念圖的差異屬必要調整：採來源可追蹤且能編輯的 GitHub 骨盆與 Blender 教學胎兒，模型內容由使用者於階段回看定稿。
