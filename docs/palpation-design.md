## 介面與分工

`PalpationModule.tsx` 管理任務與原生文字操作，`palpation.ts` 管理純狀態和條件，`PalpationViewer.tsx` 管理 GLB、相機、表面貼合及直接操作。兩種病例只改胎背方向；身分為虛構資料。無網路病人資料、帳號或臨床記錄。

任務順序：床邊準備 → 第一至四段 → 設備準備 → 兩條固定帶 → TOCO 定位 → FHR 尋訊 → 母體脈搏與舒適 → 歸零記錄 → 觀察停止 → 收尾照護 → 摘要。

示範不寫入完成狀態。直接拖曳和鍵盤替代都讀寫同一模型路徑。檢查者左手在面向頭端時接觸母體右側，不能把「左手」誤認成「母體左側」。第四段雙指朝腳端。螢幕操作僅檢查語意、方向、路徑與回答，不量測真實施力。
