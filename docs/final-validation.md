# 四模組整體檢查 2026年10月15日

本輪以程式檢查、59項Vitest、TypeScript、正式建置及Codex IAB實際操作回歸。測試直接使用按鈕、表單、鍵盤與指標，不改React內部狀態或localStorage來製造完成。

## 修正

1. 已送出的胎心率床邊情境，按「返回目前進度」會離開回看模式而允許推進原始紀錄時間。現在維持回看，按鈕改為「回到觀察終點」；只有明確重練才新增觀察。
2. 胎位與分娩的預設localStorage參數原先在try/catch外求值，瀏覽器拒絕存取時可能無法開啟。現在在保護區內取得，並保留原有保存失敗提示；測試模擬SecurityError。
3. 原根目錄模型路徑不適用GitHub Pages專案子目錄。五個三維檢視元件共用Vite BASE_URL，測試核對五個模型、兩種base與快取版本。

## QR與發布

四張QR為1160×1288 PNG，Version5/M、每模組24像素、白底及四模組安全區。以獨立ZXing-C++解碼器逐張核對，全部與links.json網址一致，無第三方QR生成服務。Pages採官方Actions、Node22及固定子目錄base；來源、完整Word規格、Blender和授權保留於儲存庫。

這是工程回歸紀錄，不宣稱沒有任何潛在錯誤。真正iPhone/iPad/Android觸控、喇叭與校內網路仍需試教核對；工程驗證不代替醫學內容與指定儀器SOP核准。
