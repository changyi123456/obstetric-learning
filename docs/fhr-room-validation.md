## 畫面與設計基線核對

對照 `fhr-scene-concept.png`，以實際 Three.js 場景取代概念圖中的照片質感。五項主要關係保留：

1. 白底全站導覽、深藍文字及青綠操作色。
2. 桌面左側主場景與右側深色監測，手機場景在前且監測緊接其後。
3. 成人半臥、病服、孕腹雙探頭與可見手腕；降低床欄遮擋並移除過亮眼部高光。
4. 詢問、核對脈搏、記錄宮縮三項操作及具體時間紀錄。
5. 共用時間軸的 FHR／TOCO、母體核對值與事件回看。

有意修正：TOCO 採相對讀值；不採虛構日期；開始鍵置於場景內便於首屏操作；加入觀察速度選擇與訊號接觸任務。人物為完整成人拓樸的教學示意模型，未聲稱真人攝影寫實。
